CHICKEN GUN: ЗАПРАВКА

Вариант 1 - просто выложить в интернет (без сетевой игры, с ботами):
  Загрузи всю эту папку на любой хостинг статических сайтов
  (Netlify Drop, GitHub Pages, Cloudflare Pages, itch.io как HTML5-игру).
  Открывается файл index.html. Модели лежат в models/, музыка в music/.

Вариант 2 - с игрой по сети:
  Нужен компьютер или хостинг с Node.js:
    npm install
    node server.js
  Открой http://IP-компьютера:3000
